# Health & Fitness Journey — plan template
Plain static HTML/CSS. Edit in `src/`, then run `./scrub.sh` to copy whitelisted files to the repo root, build `health-journey-plan.pdf` and `preview.png` (headless Chrome), and run a privacy scrub against a private pattern file kept outside the repo. The script never commits or pushes.

To publish later: push to GitHub, Settings → Pages → Deploy from branch `main`, folder `/ (root)`. `.nojekyll` is included.
